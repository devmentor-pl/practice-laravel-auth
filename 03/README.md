# `#03` Laravel: Uwierzytelnianie i autoryzacja (14-18)

Dodaj do istniejącego rozwiązania pole typu `select`, które pozwoli wybrać kategorię, do której przynależy wydatek.

Wykonaj to w taki sposób, aby dane były pobierane z tabeli `categories`, a wybór był zapisywany w formie klucza obcego. Przygotuj odpowiednie relacje w modelach.
